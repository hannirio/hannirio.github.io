### 面向过程编程 VS 面向对象编程

**面向过程编程 (Procedure-Oriented Programming)** 是一种以过程 (Procedure) 为中心的编程范式。它将解决问题的全过程拆解为一系列的步骤，并通过编写不同的函数 (Functions) 来按顺序执行这些步骤。

核心思维：关注“怎么做” (How to do it)。采用自顶向下 (Top-down) 的设计模式，逻辑呈线性 (Linear)。

数据流向：数据 (Data) 和处理数据的函数是完全分离的。数据通常以全局变量 (Global variables) 的形式在各个函数之间传递，导致安全性较低。

代表语言：C 语言。

生活类比：就像自己做炒饭。你需要按步骤来：买菜 -> 洗菜 -> 切菜 -> 开火 -> 炒饭。每一步（函数）都严格依赖上一步的结果。

---

**面向对象编程 (Object-Oriented Programming)** 是一种以对象 (Object) 为中心的编程范式。它将现实世界中的事物抽象化，将事物的属性（数据）和行为（方法）绑定在一起，形成一个独立的整体。

核心思维：关注“谁来做” (Who does it)。不再拘泥于具体的步骤，而是思考系统中有哪些对象，以及这些对象之间如何交互 (Interaction)。

三大核心特性：

- 封装 (Encapsulation)：隐藏对象的内部状态和实现细节，只对外保留公共的接口 (Public interfaces)。

- 继承 (Inheritance)：允许基于已有的类 (Classes) 创建新类，子类 (Subclasses) 可以复用父类 (Superclasses) 的代码。

- 多态 (Polymorphism)：允许不同的对象对同一个消息 (Message) 作出不同的响应，增加了代码的灵活性和扩展性 (Scalability)。

代表语言：Java, C++, Python。

生活类比：就像去餐厅点炒饭。你（对象A）只需要把需求告诉服务员（对象B），服务员通知厨师（对象C）。你不需要知道厨师具体怎么炒饭（封装），你只关心最后端上来的饭。

| 维度 (Dimension) | 面向过程编程 (POP) | 面向对象编程 (OOP) |
| :--- | :--- | :--- |
| **基础单元 (Basic Unit)** | 函数 (Functions) | 类 (Classes) 与 对象 (Objects) |
| **程序结构 (Structure)** | 步骤的集合，相互调用 | 对象的集合，相互发送消息 |
| **耦合度 (Coupling)** | 高 (High) - 修改一个功能可能影响全局 | 低 (Low) - 模块化 (Modular) 程度高 |
| **代码复用 (Code Reuse)** | 较低，主要靠函数调用 | 较高，通过继承 (Inheritance) 机制 |
| **维护性 (Maintenance)** | 较难，适合中小型或底层项目 | 较易，适合大型、复杂的商业级项目 |

### C++ 中的名称空间 (Namespace) 详解

C++中的 **名称空间（Namespace）** 主要是一项旨在帮助组织代码并解决命名冲突的特性。

在编写大型程序或将多个不同厂商的现有代码组合起来时，很容易遇到命名冲突的问题。例如，两个厂商提供的封装产品中，可能都包含了一个名为 `wanda()` 的函数。如果直接使用，编译器将无法区分应该调用哪一个版本。

为了解决这个问题，名称空间允许厂商将其代码**封装**在独立的名称空间中，通过名称来指明想使用的版本。
*   Microflop 公司的版本可以表示为全称：`Microflop::wanda()`
*   Piscine 公司的版本可以表示为全称：`Piscine::wanda()`

在现代 C++ 编译器中，标准的组件（如类、函数和变量）都被放置在了一个名为 `std` 的名称空间中。
这意味着，如果是引入没有扩展名 `.h` 的头文件（如 `<iostream>`），用于输出的 `cout` 变量实际上全称是 `std::cout`，而换行符 `endl` 实际上是 `std::endl`。

> 引入名称空间的三种方式

为了不必每次都在代码中繁琐地写出 `std::` 前缀，可以使用 `using` 指令，具体有以下三种常见情形：

*   **方式一：完全限定（不引入）**
    不使用任何 `using` 指令，直接在代码中书写 `std::cout << "Come up and C++ me some time.";`。
*   **方式二：using 编译指令 (using directive) —— 偷懒的做法**
    使用代码 `using namespace std;`。这个指令使得 `std` 名称空间中的**所有**名称都变为可用。这虽然简单，但在大型项目中可能会带来潜在的命名冲突风险。
*   **方式三：using 声明 (using declaration) —— 推荐的做法**
    这是一种更好的方法，只让代码中实际需要的特定名称可用。例如：
    `using std::cout; // make cout available`
    `using std::endl; // make endl available`
    采用这种方式后，就可以直接使用 `cout` 和 `endl`，而对于 `std` 中其他未声明的名称，仍然需要加上 `std::` 前缀。

### C++ std 名称空间常用内容概览

`std`（Standard）名称空间包含了整个 **C++ 标准库（Standard Library）** 的内容。它里面不仅有函数，还包含了大量的类（Classes）、对象（Objects）、数据结构和模板。

由于内容极其庞大，通常我们需要根据功能引入不同的头文件（如 `<iostream>`, `<vector>`, `<cmath>` 等）来使用它们。以下是 `std` 名称空间中最常用的一些核心分类及代表性成员：

#### 1. 输入与输出 (I/O)
*通常需要引入 `<iostream>` 头文件*
*   **`std::cout`**：标准输出对象（向屏幕打印内容）。
*   **`std::cin`**：标准输入对象（从键盘接收内容）。
*   **`std::endl`**：换行符函数，同时会刷新输出缓冲区。
*   **`std::getline()`**：读取一整行字符串的函数。

#### 2. 常用算法 (Algorithms)
*通常需要引入 `<algorithm>` 头文件*
*   **`std::sort()`**：对数组或容器中的元素进行排序。
*   **`std::find()`**：在数据集合中查找特定元素。
*   **`std::max()` / `std::min()`**：返回两个值中的最大值或最小值。
*   **`std::reverse()`**：反转元素的顺序。

#### 3. 数学计算 (Math)
*通常需要引入 `<cmath>` 头文件*
*   **`std::abs()`**：计算绝对值。
*   **`std::pow()`**：计算次幂（如 $x^y$）。
*   **`std::sqrt()`**：计算平方根。
*   **`std::round()`**：四舍五入取整。

#### 4. 字符串处理 (Strings)
*通常需要引入 `<string>` 头文件*
*   **`std::string`**：C++ 中极其常用的字符串类。
*   **`std::to_string()`**：将数字转换为字符串的函数。
*   **`std::stoi()` / `std::stod()`**：将字符串转换为整数（Integer）或双精度浮点数（Double）。

#### 5. 容器与数据结构 (Containers)
*需要引入对应的头文件，如 `<vector>`, `<map>`, `<set>`*
*   **`std::vector`**：动态数组（可自动扩容的数组）。
*   **`std::map`**：字典/关联数组（存储键值对 Key-Value）。
*   **`std::set`**：集合（存储唯一元素的集合）。

#### 6. 内存管理 (Memory Management)
*通常需要引入 `<memory>` 头文件*
*   **`std::make_shared()` / `std::make_unique()`**：用于安全创建智能指针的函数，帮助开发者避免内存泄漏。

> **总结：** C++ 标准库涵盖了日常开发的方方面面。在实际编程中，只要是 C++ 官方提供的基础工具，几乎都需要加上 `std::` 前缀（或者通过 `using` 声明）来调用。

### C++的简单变量
关于有符号整数变量
```cpp

#include<bits/stdc++.h>

using namespace std;

int main(){
    int n_int = INT_MAX;
    short n_short = SHRT_MAX;
    long n_long = LONG_MAX;
    long long n_long_long = LLONG_MAX;
    
    // sizeof() 返回某个数据类型或特定变量在系统内存中所占用的字节数（bytes）
    cout << "int is " << sizeof(n_int) << " bytes" << endl;
    cout << "short is " << sizeof(n_short) << " bytes" << endl;
    cout << "long is " << sizeof(n_long) << " bytes" << endl;
    cout << "long long is " << sizeof(n_long_long) << " bytes" << endl;
    cout << "int max value is " << n_int << endl;
    cout << "short max value is " << n_short << endl;
    cout << "long max value is " << n_long << endl;
    cout << "long long max value is " << n_long_long << endl;
    return 0;
}
```
以上代码输出结果:

```

short is 2 bytes
long is 8 bytes
long long is 8 bytes
int max value is 2147483647
short max value is 32767
long max value is 9223372036854775807
long long max value is 9223372036854775807
```

C++ 代码中的进制表示（字面量写法）
在代码中直接写数字时，可以通过不同的前缀来告诉编译器你使用的是哪种进制：

`十进制 (Decimal)`：默认进制，不加任何前缀。第一位不能是 0（除非数字本身就是 0）。例如：`int a = 42`;

`八进制 (Octal)`：以数字 0 开头。例如：int b = 042; （十进制的 34）

`十六进制 (Hexadecimal)`：以 0x 或 0X 开头。例如：int c = 0x42; （十进制的 66）

`二进制 (Binary)`：以 0b 或 0B 开头（C++14 标准引入，你当前的编译环境已完全支持）。例如：int d = 0b101010; （十进制的 42）

使用 `cout` 输出不同进制`std::cout` 默认以十进制格式输出整数。要输出其他进制，需要向 cout 发送控制符（Manipulators）。

`std::dec`：切换为十进制输出（默认）。

`std::oct`：切换为八进制输出。

`std::hex`：切换为十六进制输出。

```cpp

#include <iostream>
#include <bitset> // 用于输出二进制

using namespace std;

int main() {
    int num = 42;

    // 输出十进制、十六进制、八进制
    cout << "Decimal: " << num << endl;
    cout << "Hexadecimal: " << hex << num << endl;
    cout << "Octal: " << oct << num << endl;

    // 注意：此时 cout 仍然处于八进制状态，需要恢复十进制
    cout << dec; 
    cout << "Back to Decimal: " << num << endl;

    // 输出二进制（cout 没有内置的二进制控制符，需借用 bitset）
    // bitset<8> 表示输出 8 位长度的二进制
    cout << "Binary: " << bitset<8>(num) << endl; 

    int chest = 42;
    int waist = 042;  // 八进制表示
    int mouth = 0x42;
    cout << "chest: " << chest << endl; // 十进制输出
    cout << "waist: " << waist << endl; // 八进制输出
    cout << "mouth: " << mouth << endl; // 十六进制输出

    return 0;
}
```

对应的输出为

```

Decimal: 42
Hexadecimal: 2a
Octal: 52
Back to Decimal: 42
Binary: 00101010
chest: 42
waist: 34
mouth: 66
```

### ASCII码
计算机底层只能理解数字（0 和 1）。为了让计算机能处理文本（如字母、标点符号），我们需要一套“密码本”，将每个字符映射成一个数字。ASCII 码就是最基础的这样一套映射标准。

在 C++ 中，`char（字符型）`变量在内存中实际上存储的是整数（即该字符对应的 ASCII 码值）。

`cout` 通常与流插入运算符 `<<` 一起使用来输出各种类型的数据。而 `cout.put()` 是 C++ ostream 类的一个专门的成员函数，它的作用非常单一：<u>只输出一个单独的字符。</u>

特点：
- 它接收一个 'char' 类型的参数。

- 如果你传给它一个整数（比如 '65'），它会将其隐式转换为对应的 ASCII 字符（即 'A'）并输出。

它可以链式调用，例如 `cout.put('A').put('B');` 。



```cpp

#include<bits/stdc++.h>
using namespace std;

int main(){
    char ch = 'M';
    int i = ch;
    cout << "\aThe ASCII value of " << ch << " is " << i<< endl;
    // ASCII码
    ch = ch + 1;
    i = ch;
    cout << "The ASCII value of " << ch << " is " << i << endl;
    cout << "Display char ch using cout.put(ch): ";
    cout.put(ch);
    cout.put('!');
    cout.put('\n');
    cout.put(77); // 输出: M (因为 77 是 'M' 的 ASCII 码)
    return 0;
}
```

对应的输出结果：
```

The ASCII value of M is 77
The ASCII value of N is 78
Display char ch using cout.put(ch): N!
M%    
```

### const限定符
****

C++中的 `const`（constant的缩写）是一个非常核心的关键字，它的主要作用是**向编译器声明一个变量、指针或函数是“只读”的**。通过强制执行不可变性，`const` 能够极大地减少程序中的意外修改，提升代码的安全性和可读性。

以下是 `const` 在 C++ 中的 5 个核心应用场景：

#### 1. 修饰基础变量
最基本的用法是定义一个不可变的常量。**注意：`const` 变量必须在声明时进行初始化。**
```cpp

const int MAX_USERS = 100;
// MAX_USERS = 200; // 编译错误：MAX_USERS 是只读的
```

#### 2. 修饰指针（易混淆点）
`const` 与指针结合时，初学者往往容易搞混。判断 `const` 到底修饰谁，有一个极其有效的经典规则：**“从右往左读”**（或者看 `const` 在 `*` 的左边还是右边）。

*   **常量指针 (Pointer to Const)**
    `const` 在 `*` 的左边。表示**指针指向的数据**不可修改，但指针本身的指向可以改变。
    ```cpp

    int x = 10, y = 20;
    const int* p1 = &x; // (或者 int const* p1)
    // *p1 = 30;        // 错误：不能通过 p1 修改 x 的值
    p1 = &y;            // 正确：p1 可以转而指向 y
    ```
*   **指针常量 (Const Pointer)**
    `const` 在 `*` 的右边。表示**指针本身的地址**不可改变，但可以通过指针修改其指向的数据。
    ```cpp

    int* const p2 = &x;
    *p2 = 30;           // 正确：可以修改 x 的值
    // p2 = &y;         // 错误：p2 的指向不能改变
    ```
*   **指向常量的常量指针**
    ```cpp

    const int* const p3 = &x; // 指向和数据都被锁定，均不可修改
    ```

#### 3. 修饰引用（最常用的传参方式）
在函数传参时，如果直接传递大型对象（如 `std::string` 或自定义类），会产生高昂的内存拷贝代价。如果按普通引用传递，又存在数据被函数内部意外修改的风险。**常引用 (`const Type&`)** 完美解决了这个问题：
```cpp

void printUser(const std::string& username) {
    // username += "_admin"; // 错误：无法修改常引用
    std::cout << username << std::endl;
}
```
> **最佳实践**：除基础类型（如 `int`, `char`）外，向函数传递对象时，只要不打算在函数内修改它，都应默认使用 `const Type&`。

#### 4. 修饰类的成员函数
在类中，如果一个成员函数只是读取数据而不修改任何成员变量，应该在函数声明末尾加上 `const`。
```cpp

class Account {
private:
    int balance = 1000;
public:
    // const 成员函数承诺不修改对象状态
    int getBalance() const { 
        // balance += 100; // 错误：const 函数内不能修改普通成员变量
        return balance;
    }
};
```
**关键限制**：**`const` 对象只能调用 `const` 成员函数**。如果 `getBalance()` 没加 `const`，那么一个 `const Account` 对象将无法调用该方法。

*(注：如果确实需要在 `const` 函数中修改某个特定变量——例如用于统计函数被调用次数的计数器，或者互斥锁，可以使用 `mutable` 关键字修饰该成员变量，让其豁免 `const` 限制。)*

#### 5. const 与 constexpr 的区别 (C++11)
现代 C++ 引入了 `constexpr`，两者容易混淆，但它们的侧重点不同：
*   **`const`**：意思是“我承诺在这个作用域内不修改它”。它的值可以在**运行时**才计算出来。
*   **`constexpr`**：意思是“真正的编译期常量”。它的值必须在**编译阶段**就能完全确定，常用于数组大小、模板参数等极其严格的场景。

**核心思想（Const Correctness 常量正确性）**：只要一个值、指针或对象不需要被修改，就应该毫不犹豫地给它加上 `const`。这不仅是给编译器的优化提示，更是写给其他程序员的“防呆”文档。

### C++浮点数

C++ 中的浮点数用于表示带有小数部分的实数。由于计算机内存是有限的，C++（以及绝大多数现代编程语言）采用 **IEEE 754 标准**来存储浮点数，这意味着它们本质上是**对真实数值的近似**，而不是绝对精确的值。

#### 1. 三大基础类型对比

C++ 提供了三种浮点类型，它们的精度和内存占用依次递增：

| 类型 | 典型内存占用 | 有效数字精度 | 字面量后缀 | 默认使用场景 |
| :--- | :--- | :--- | :--- | :--- |
| `float` | 4 字节 (32位) | 约 6-7 位 | `f` 或 `F` (如 `3.14f`) | 显卡编程、3D图形学（如 OpenGL）、对内存极其敏感的场景 |
| `double` | 8 字节 (64位) | 约 15-17 位 | 无后缀 (如 `3.14`) | **默认首选**，绝大多数科学计算和日常业务 |
| `long double` | 8/12/16 字节 | 约 18-21 位 | `l` 或 `L` (如 `3.14L`) | 极高精度的天文学或物理学计算（依赖具体编译器实现） |

> **注意字面量陷阱**：在 C++ 中，直接写出的纯小数（如 `3.14`）默认是 `double` 类型。如果你写 `float x = 3.14;`，编译器会隐式将 `double` 截断为 `float`。必须写成 `float x = 3.14f;` 才是真正的 `float`。

#### 2. 核心痛点：精度丢失

由于底层采用二进制科学计数法（符号位 + 指数位 + 尾数位）存储，很多十进制下很简单的小数（如 `0.1`）在二进制中是无限循环小数。这就导致了经典的精度丢失问题。

```cpp

double a = 0.1;
double b = 0.2;
double c = 0.3;

if (a + b == c) {
    std::cout << "相等"; 
} else {
    std::cout << "不相等"; // 实际会输出这个！因为 a+b 可能是 0.30000000000000004
}
```

#### 3. 浮点数比较的正确姿势

因为存在精度误差，永远不要对两个浮点数使用` == `或` != `进行直接比较。
正确的做法是引入一个极小的误差范围（称为 `epsilon`），只要两个数的差值绝对值小于这个范围，就认为它们相等。

```cpp

#include <iostream>
#include <cmath>
#include <limits>

bool isNearlyEqual(double a, double b) {
    // std::numeric_limits<double>::epsilon() 返回 double 类型能表示的最小差值
    return std::abs(a - b) <= std::numeric_limits<double>::epsilon();
    
    // 或者自定义一个固定精度，例如 1e-9
    // return std::abs(a - b) < 1e-9; 
}
```

#### 4. 浮点数开发的最佳实践
默认使用 double：在现代 CPU 架构上，float 和 double 的计算速度基本一样快（甚至 double 更快，因为硬件 FPU 寄存器通常是 64 位及以上的），但 double 的精度高得多。

绝对不要用浮点数存金额：像 0.1 这样的数字在浮点数中是不精确的。在金融和电商系统中，处理货币要么使用特定的定点数库，要么将单位转换为最小整数（如把“12.34元”存为整数的 1234 分）。

避免数量级差异过大的加减法：如果用 100000000.0 + 0.000000001，较小的值会因为超出有效数字范围而被直接“吃掉”（大数吃小数）。

示例代码如下：
```cpp

#include<bits/stdc++.h>
using namespace std;

int main(){
    float a = 2.34E+22f;  // 2.34 * 10^22
    // 2.34 * 10^22 + 1.0,float has 7 significant digits, so the result will be rounded to 2.34 * 10^22
    float b = a + 1.0f;   
    cout << "a = " << a << endl;
    cout << "b - a = " << b - a << endl;  // 相当于往大海里滴一滴水
    return 0;
}

// 运行结果
a = 2.34e+22
b - a = 0
```

### 面向过程编程 VS 面向对象编程

**面向过程编程 (Procedure-Oriented Programming)** 是一种以过程 (Procedure) 为中心的编程范式。它将解决问题的全过程拆解为一系列的步骤，并通过编写不同的函数 (Functions) 来按顺序执行这些步骤。

核心思维：关注“怎么做” (How to do it)。采用自顶向下 (Top-down) 的设计模式，逻辑呈线性 (Linear)。

数据流向：数据 (Data) 和处理数据的函数是完全分离的。数据通常以全局变量 (Global variables) 的形式在各个函数之间传递，导致安全性较低。

代表语言：C 语言。

生活类比：就像自己做炒饭。你需要按步骤来：买菜 -> 洗菜 -> 切菜 -> 开火 -> 炒饭。每一步（函数）都严格依赖上一步的结果。

---

**面向对象编程 (Object-Oriented Programming)** 是一种以对象 (Object) 为中心的编程范式。它将现实世界中的事物抽象化，将事物的属性（数据）和行为（方法）绑定在一起，形成一个独立的整体。

核心思维：关注“谁来做” (Who does it)。不再拘泥于具体的步骤，而是思考系统中有哪些对象，以及这些对象之间如何交互 (Interaction)。

三大核心特性：

- 封装 (Encapsulation)：隐藏对象的内部状态和实现细节，只对外保留公共的接口 (Public interfaces)。

- 继承 (Inheritance)：允许基于已有的类 (Classes) 创建新类，子类 (Subclasses) 可以复用父类 (Superclasses) 的代码。

- 多态 (Polymorphism)：允许不同的对象对同一个消息 (Message) 作出不同的响应，增加了代码的灵活性和扩展性 (Scalability)。

代表语言：Java, C++, Python。

生活类比：就像去餐厅点炒饭。你（对象A）只需要把需求告诉服务员（对象B），服务员通知厨师（对象C）。你不需要知道厨师具体怎么炒饭（封装），你只关心最后端上来的饭。

| 维度 (Dimension) | 面向过程编程 (POP) | 面向对象编程 (OOP) |
| :--- | :--- | :--- |
| **基础单元 (Basic Unit)** | 函数 (Functions) | 类 (Classes) 与 对象 (Objects) |
| **程序结构 (Structure)** | 步骤的集合，相互调用 | 对象的集合，相互发送消息 |
| **耦合度 (Coupling)** | 高 (High) - 修改一个功能可能影响全局 | 低 (Low) - 模块化 (Modular) 程度高 |
| **代码复用 (Code Reuse)** | 较低，主要靠函数调用 | 较高，通过继承 (Inheritance) 机制 |
| **维护性 (Maintenance)** | 较难，适合中小型或底层项目 | 较易，适合大型、复杂的商业级项目 |

### C++ 中的名称空间 (Namespace) 详解

C++中的 **名称空间（Namespace）** 主要是一项旨在帮助组织代码并解决命名冲突的特性。

在编写大型程序或将多个不同厂商的现有代码组合起来时，很容易遇到命名冲突的问题。例如，两个厂商提供的封装产品中，可能都包含了一个名为 `wanda()` 的函数。如果直接使用，编译器将无法区分应该调用哪一个版本。

为了解决这个问题，名称空间允许厂商将其代码**封装**在独立的名称空间中，通过名称来指明想使用的版本。
*   Microflop 公司的版本可以表示为全称：`Microflop::wanda()`
*   Piscine 公司的版本可以表示为全称：`Piscine::wanda()`

在现代 C++ 编译器中，标准的组件（如类、函数和变量）都被放置在了一个名为 `std` 的名称空间中。
这意味着，如果是引入没有扩展名 `.h` 的头文件（如 `<iostream>`），用于输出的 `cout` 变量实际上全称是 `std::cout`，而换行符 `endl` 实际上是 `std::endl`。

> 引入名称空间的三种方式

为了不必每次都在代码中繁琐地写出 `std::` 前缀，可以使用 `using` 指令，具体有以下三种常见情形：

*   **方式一：完全限定（不引入）**
    不使用任何 `using` 指令，直接在代码中书写 `std::cout << "Come up and C++ me some time.";`。
*   **方式二：using 编译指令 (using directive) —— 偷懒的做法**
    使用代码 `using namespace std;`。这个指令使得 `std` 名称空间中的**所有**名称都变为可用。这虽然简单，但在大型项目中可能会带来潜在的命名冲突风险。
*   **方式三：using 声明 (using declaration) —— 推荐的做法**
    这是一种更好的方法，只让代码中实际需要的特定名称可用。例如：
    `using std::cout; // make cout available`
    `using std::endl; // make endl available`
    采用这种方式后，就可以直接使用 `cout` 和 `endl`，而对于 `std` 中其他未声明的名称，仍然需要加上 `std::` 前缀。

### C++ std 名称空间常用内容概览

`std`（Standard）名称空间包含了整个 **C++ 标准库（Standard Library）** 的内容。它里面不仅有函数，还包含了大量的类（Classes）、对象（Objects）、数据结构和模板。

由于内容极其庞大，通常我们需要根据功能引入不同的头文件（如 `<iostream>`, `<vector>`, `<cmath>` 等）来使用它们。以下是 `std` 名称空间中最常用的一些核心分类及代表性成员：

#### 1. 输入与输出 (I/O)
*通常需要引入 `<iostream>` 头文件*
*   **`std::cout`**：标准输出对象（向屏幕打印内容）。
*   **`std::cin`**：标准输入对象（从键盘接收内容）。
*   **`std::endl`**：换行符函数，同时会刷新输出缓冲区。
*   **`std::getline()`**：读取一整行字符串的函数。

#### 2. 常用算法 (Algorithms)
*通常需要引入 `<algorithm>` 头文件*
*   **`std::sort()`**：对数组或容器中的元素进行排序。
*   **`std::find()`**：在数据集合中查找特定元素。
*   **`std::max()` / `std::min()`**：返回两个值中的最大值或最小值。
*   **`std::reverse()`**：反转元素的顺序。

#### 3. 数学计算 (Math)
*通常需要引入 `<cmath>` 头文件*
*   **`std::abs()`**：计算绝对值。
*   **`std::pow()`**：计算次幂（如 $x^y$）。
*   **`std::sqrt()`**：计算平方根。
*   **`std::round()`**：四舍五入取整。

#### 4. 字符串处理 (Strings)
*通常需要引入 `<string>` 头文件*
*   **`std::string`**：C++ 中极其常用的字符串类。
*   **`std::to_string()`**：将数字转换为字符串的函数。
*   **`std::stoi()` / `std::stod()`**：将字符串转换为整数（Integer）或双精度浮点数（Double）。

#### 5. 容器与数据结构 (Containers)
*需要引入对应的头文件，如 `<vector>`, `<map>`, `<set>`*
*   **`std::vector`**：动态数组（可自动扩容的数组）。
*   **`std::map`**：字典/关联数组（存储键值对 Key-Value）。
*   **`std::set`**：集合（存储唯一元素的集合）。

#### 6. 内存管理 (Memory Management)
*通常需要引入 `<memory>` 头文件*
*   **`std::make_shared()` / `std::make_unique()`**：用于安全创建智能指针的函数，帮助开发者避免内存泄漏。

> **总结：** C++ 标准库涵盖了日常开发的方方面面。在实际编程中，只要是 C++ 官方提供的基础工具，几乎都需要加上 `std::` 前缀（或者通过 `using` 声明）来调用。

### C++的简单变量
关于有符号整数变量
```cpp

#include<bits/stdc++.h>

using namespace std;

int main(){
    int n_int = INT_MAX;
    short n_short = SHRT_MAX;
    long n_long = LONG_MAX;
    long long n_long_long = LLONG_MAX;
    
    // sizeof() 返回某个数据类型或特定变量在系统内存中所占用的字节数（bytes）
    cout << "int is " << sizeof(n_int) << " bytes" << endl;
    cout << "short is " << sizeof(n_short) << " bytes" << endl;
    cout << "long is " << sizeof(n_long) << " bytes" << endl;
    cout << "long long is " << sizeof(n_long_long) << " bytes" << endl;
    cout << "int max value is " << n_int << endl;
    cout << "short max value is " << n_short << endl;
    cout << "long max value is " << n_long << endl;
    cout << "long long max value is " << n_long_long << endl;
    return 0;
}
```
以上代码输出结果:

```

int is 4 bytes
short is 2 bytes
long is 8 bytes
long long is 8 bytes
int max value is 2147483647
short max value is 32767
long max value is 9223372036854775807
long long max value is 9223372036854775807
```

关于无符号数的溢出，理解为一个环状的钟表🕙
```cpp

#include<bits/stdc++.h>
#define ZERO 0
using namespace std;

int main(){
    short sam = SHRT_MAX;
    unsigned short sue = sam;
    cout << "sam = " << sam << endl;
    cout << "sue = " << sue << endl;
    sam = sam + 1;
    sue = sue + 1;
    cout << "sam + 1= " << sam << endl;
    cout << "sue + 1= " << sue << endl;
    cout << "----清零后的值----" << endl;
    sam = ZERO;
    sue = ZERO;
    cout << "sam = " << sam << endl;
    cout << "sue = " << sue << endl;
    sam = sam - 1;
    sue = sue - 1;
    cout << "sam - 1 =  " << sam << endl;
    cout << "sue - 1 =  " << sue << endl;
    return 0;
}
```
对应的输出结果：
```

sam = 32767
sue = 32767
sam + 1= -32768
sue + 1= 32768
----清零后的值----
sam = 0
sue = 0
sam - 1 =  -1
sue - 1 =  65535
```

C++ 代码中的进制表示（字面量写法）
在代码中直接写数字时，可以通过不同的前缀来告诉编译器你使用的是哪种进制：

`十进制 (Decimal)`：默认进制，不加任何前缀。第一位不能是 0（除非数字本身就是 0）。例如：`int a = 42`;

`八进制 (Octal)`：以数字 0 开头。例如：int b = 042; （十进制的 34）

`十六进制 (Hexadecimal)`：以 0x 或 0X 开头。例如：int c = 0x42; （十进制的 66）

`二进制 (Binary)`：以 0b 或 0B 开头（C++14 标准引入，你当前的编译环境已完全支持）。例如：int d = 0b101010; （十进制的 42）

使用 `cout` 输出不同进制`std::cout` 默认以十进制格式输出整数。要输出其他进制，需要向 cout 发送控制符（Manipulators）。

`std::dec`：切换为十进制输出（默认）。

`std::oct`：切换为八进制输出。

`std::hex`：切换为十六进制输出。

```cpp

#include <iostream>
#include <bitset> // 用于输出二进制

using namespace std;

int main() {
    int num = 42;

    // 输出十进制、十六进制、八进制
    cout << "Decimal: " << num << endl;
    cout << "Hexadecimal: " << hex << num << endl;
    cout << "Octal: " << oct << num << endl;

    // 注意：此时 cout 仍然处于八进制状态，需要恢复十进制
    cout << dec; 
    cout << "Back to Decimal: " << num << endl;

    // 输出二进制（cout 没有内置的二进制控制符，需借用 bitset）
    // bitset<8> 表示输出 8 位长度的二进制
    cout << "Binary: " << bitset<8>(num) << endl; 

    int chest = 42;
    int waist = 042;  // 八进制表示
    int mouth = 0x42;
    cout << "chest: " << chest << endl; // 十进制输出
    cout << "waist: " << waist << endl; // 八进制输出
    cout << "mouth: " << mouth << endl; // 十六进制输出

    return 0;
}
```

对应的输出为

```

Decimal: 42
Hexadecimal: 2a
Octal: 52
Back to Decimal: 42
Binary: 00101010
chest: 42
waist: 34
mouth: 66
```

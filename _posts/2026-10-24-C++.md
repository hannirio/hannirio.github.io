### 面向过程编程 VS 面向对象编程

**面向过程编程 (Procedure-Oriented Programming, POP)** 是一种以过程（Procedure）为中心的编程范式。它将解决问题的全过程拆解为一系列步骤，并通过编写不同的函数（Functions）按顺序执行这些步骤。

- **核心思维**：关注“怎么做”（How to do it）。采用自顶向下（Top-down）的设计模式，逻辑呈线性（Linear）展开。
- **数据流向**：数据（Data）与处理数据的函数完全分离。数据通常以全局变量或参数的形式在各个函数之间传递，封装性与安全性相对较低。
- **代表语言**：C 语言。
- **生活类比**：就像自己在家做蛋炒饭，需要严格按步骤推进：`买菜 -> 洗菜 -> 切菜 -> 开火 -> 炒饭`。每一步（函数）都紧扣并依赖上一步的结果。

---

**面向对象编程 (Object-Oriented Programming, OOP)** 是一种以对象（Object）为中心的编程范式。它将现实世界中的事物抽象化，把事物的**属性（数据）**和**行为（方法）**绑定在一起，构成一个高内聚的独立整体。

- **核心思维**：关注“谁来做”（Who does it）。不再过度拘泥于底层的具体步骤，而是先划分系统中有哪些对象，以及这些对象之间如何协作与交互（Interaction）。
- **三大核心特性**：
  - **封装 (Encapsulation)**：隐藏对象的内部状态和实现细节，仅对外暴露安全、规范的公共接口（Public Interfaces）。
  - **继承 (Inheritance)**：允许基于已有的类（Classes）派生新类，子类（Subclasses）可以复用并扩展父类（Superclasses）的代码。
  - **多态 (Polymorphism)**：允许不同类的对象对同一消息（Message / 函数调用）作出不同的响应，显著提升了代码的灵活性与可扩展性（Scalability）。
- **代表语言**：C++、Java、Python。
- **生活类比**：就像去餐厅点炒饭。你（对象 A）只需把需求告诉服务员（对象 B），服务员再通知厨师（对象 C）。你无需关心厨师具体如何颠勺炒饭（封装），只需接收最终端上桌的成品。

| 维度 (Dimension)           | 面向过程编程 (POP)               | 面向对象编程 (OOP)                 |
| :------------------------- | :------------------------------- | :--------------------------------- |
| **基础单元 (Basic Unit)**  | 函数 (Functions)                 | 类 (Classes) 与对象 (Objects)      |
| **程序结构 (Structure)**   | 步骤的集合，函数间顺序调用       | 对象的集合，对象间传递消息         |
| **耦合度 (Coupling)**      | 较高 —— 修改一处逻辑可能牵动全局 | 较低 —— 模块化（Modular）程度高    |
| **代码复用 (Code Reuse)**  | 较低，主要依赖函数调用           | 较高，通过继承、组合与多态机制实现 |
| **可维护性 (Maintenance)** | 适合中小型项目或底层系统开发     | 适合大型、复杂的工程级项目         |

### C++ 中的名称空间 (Namespace) 详解

C++ 中的**名称空间（Namespace）**是一项用于组织代码逻辑、隔离作用域并解决**命名冲突（Name Collision）**的核心特性。

在编写大型程序或整合多个第三方库时，极易遇到标识符重名的问题。例如，两个不同厂商提供的库中可能都包含名为 `wanda()` 的函数。如果直接引入并调用，编译器将无法区分应该链接哪一个版本。

名称空间允许开发者将代码封装在独立的命名作用域中，通过**作用域解析运算符 `::`** 来明确指定所使用的版本：

- Microflop 公司的版本可表示为：`Microflop::wanda()`
- Piscine 公司的版本可表示为：`Piscine::wanda()`

在现代 C++ 标准中，所有标准库组件（类、函数、对象和模板）都被放置在名为 `std` 的名称空间内。因此，当引入不带 `.h` 扩展名的标准头文件（如 `<iostream>`）时，标准输出流对象 `cout` 的完整限定名实际上是 `std::cout`，换行操纵符 `endl` 则是 `std::endl`。

> **引入名称空间的三种常用方式**

为了避免每次都在代码中重复书写 `std::` 前缀，C++ 提供了灵活的引入策略：

- **方式一：完全限定名（最安全）**
  不使用任何 `using` 语法，每次调用时显式写出前缀：
  ```cpp
  std::cout << "Come up and C++ me some time." << std::endl;
  ```
- **方式二：`using` 编译指令 (Using Directive) —— 适合小型练习，工程中慎用**
  使用 `using namespace std;` 将 `std` 名称空间中的**所有**标识符一次性暴露到当前作用域。虽然书写省事，但在大型项目中（尤其是头文件里）极易引发命名污染与冲突。
- **方式三：`using` 声明 (Using Declaration) —— 推荐折中方案**
  按需引入代码中实际用到的特定标识符：
  ```cpp
  using std::cout; // 仅使 cout 直接可用
  using std::endl; // 仅使 endl 直接可用
  ```
  采用这种方式后，可以直接书写 `cout` 和 `endl`，而 `std` 中的其他未声明成员仍受名称空间保护。

### C++ `std` 标准库常用内容概览

`std`（Standard）名称空间囊括了整个 **C++ 标准库（Standard Library）**。使用时需根据功能按需引入对应的头文件。以下是日常开发中最核心的六大模块及代表成员：

#### 1. 输入与输出 (I/O)

_头文件：`<iostream>`、`<string>`_

- **`std::cout`**：标准输出流对象（向控制台打印内容）。
- **`std::cin`**：标准输入流对象（从键盘接收输入）。
- **`std::endl`**：流操纵符，输出换行符 `\n` 并强制刷新输出缓冲区（Buffer）。
- **`std::getline()`**：从输入流读取包含空格的一整行内容到 `std::string` 中。

#### 2. 常用算法 (Algorithms)

_头文件：`<algorithm>`_

- **`std::sort()`**：对数组或容器区间内的元素进行高效排序。
- **`std::find()`**：在指定区间内查找特定元素。
- **`std::max()` / `std::min()`**：返回两个值中的较大值或较小值。
- **`std::reverse()`**：反转区间内元素的排列顺序。

#### 3. 数学计算 (Math)

_头文件：`<cmath>`_

- **`std::abs()`**：计算绝对值。
- **`std::pow()`**：计算幂运算（如 $x^y$）。
- **`std::sqrt()`**：计算算术平方根。
- **`std::round()`**：四舍五入取整。

#### 4. 字符串处理 (Strings)

_头文件：`<string>`_

- **`std::string`**：C++ 标准字符串类，支持动态扩缩容与丰富的文本操作。
- **`std::to_string()`**：将数值类型转换为 `std::string`。
- **`std::stoi()` / `std::stod()`**：将字符串解析为整数（`int`）或双精度浮点数（`double`）。

#### 5. 容器与数据结构 (Containers)

_头文件：`<vector>`、`<map>`、`<set>` 等_

- **`std::vector`**：动态数组（连续内存布局，支持随机访问与自动扩容）。
- **`std::map`**：有序关联容器（底层通常为红黑树，按 Key-Value 键值对存储）。
- **`std::set`**：有序集合（元素唯一且自动排序）。

#### 6. 现代内存管理 (Memory Management)

_头文件：`<memory>`_

- **`std::make_unique()` / `std::make_shared()`**：用于安全创建独占智能指针（`std::unique_ptr`）与共享智能指针（`std::shared_ptr`），借助 RAII 机制自动管理堆内存，避免内存泄漏。

> **小结**：只要是 C++ 标准库提供的工具，均位于 `std` 名称空间下，调用时需加上 `std::` 前缀或通过 `using` 声明引入。

### C++ 的整型变量与数值溢出

#### 1. 有符号整型的字节大小与极值

C++ 提供了不同位宽的整型：抓准 `short`、`int`、`long` 和 `long long` 在目标平台上的内存占用与表示范围非常重要（各类型的极值常量定义在 `<climits>` 头文件中）：

```cpp
#include <iostream>
#include <climits>

using namespace std;

int main() {
    int n_int = INT_MAX;
    short n_short = SHRT_MAX;
    long n_long = LONG_MAX;
    long long n_long_long = LLONG_MAX;

    // sizeof 运算符返回类型或变量在当前系统中占用的字节数（bytes）
    cout << "int is " << sizeof(n_int) << " bytes" << endl;
    cout << "short is " << sizeof(n_short) << " bytes" << endl;
    cout << "long is " << sizeof(n_long) << " bytes" << endl;
    cout << "long long is " << sizeof(n_long_long) << " bytes" << endl;

    cout << "int max value is " << n_int << endl;
    cout << "short max value is " << n_short << endl;
    cout << "long max value is " << n_long << endl;
    cout << "long long max value is " << n_long_long << endl;
    return 0;
}
```

输出结果（64 位 macOS / Linux LP64 模型）：

```text
int is 4 bytes
short is 2 bytes
long is 8 bytes
long long is 8 bytes
int max value is 2147483647
short max value is 32767
long max value is 9223372036854775807
long long max value is 9223372036854775807
```

#### 2. 整型溢出与回绕现象

可以把整型的表示范围形象地理解为一个**首尾相连的环形里程表（或钟表 🕙）**。当数值超过类型能表示的上限或下限时，就会发生回绕（Wrap-around）：

- **无符号整数（Unsigned）**的回绕是 C++ 标准明确定义的模运算行为（如 16 位无符号数 `0 - 1` 会回绕到 `65535`）。
- **有符号整数（Signed）**溢出在 C++ 标准中属于未定义行为（Undefined Behavior），但在采用二进制补码的现代计算机上，通常表现为从最大值跳转到最小值（如 `32767 + 1` 变为 `-32768`）。

```cpp
#include <iostream>
#include <climits>
#define ZERO 0

using namespace std;

int main() {
    short sam = SHRT_MAX;
    unsigned short sue = sam;

    cout << "sam = " << sam << endl;
    cout << "sue = " << sue << endl;

    sam = sam + 1; // 有符号数越过上限，跳转至负的最大值 -32768
    sue = sue + 1; // 无符号数上限为 65535，加 1 后正常变为 32768
    cout << "sam + 1 = " << sam << endl;
    cout << "sue + 1 = " << sue << endl;

    cout << "---- 清零后的值 ----" << endl;
    sam = ZERO;
    sue = ZERO;
    cout << "sam = " << sam << endl;
    cout << "sue = " << sue << endl;

    sam = sam - 1; // 有符号数 0 - 1 正常得到 -1
    sue = sue - 1; // 无符号数越过下限 0，回绕至最大值 65535
    cout << "sam - 1 = " << sam << endl;
    cout << "sue - 1 = " << sue << endl;
    return 0;
}
```

输出结果：

```text
sam = 32767
sue = 32767
sam + 1 = -32768
sue + 1 = 32768
---- 清零后的值 ----
sam = 0
sue = 0
sam - 1 = -1
sue - 1 = 65535
```

### C++ 中的进制表示与格式化输出

#### 1. 整型字面量的进制写法

在代码中书写数字常量时，可以通过特定前缀指定进制：

- **十进制 (Decimal)**：默认进制，无前缀，首位不能为 `0`（数字 `0` 本身除外）。例如：`int a = 42;`
- **八进制 (Octal)**：以数字 `0` 开头。例如：`int b = 042;`（对应十进制的 `34`）
- **十六进制 (Hexadecimal)**：以 `0x` 或 `0X` 开头。例如：`int c = 0x42;`（对应十进制的 `66`）
- **二进制 (Binary)**：以 `0b` 或 `0B` 开头（C++14 标准引入）。例如：`int d = 0b101010;`（对应十进制的 `42`）

#### 2. 使用 `cout` 控制输出进制

不管字面量用什么进制书写，内存中一律以二进制存储，而 `std::cout` 默认以**十进制**格式输出整数。若要切换输出进制，可向输出流传入控制符（Manipulators）：

- **`std::dec`**：切换为十进制输出（默认状态）。
- **`std::oct`**：切换为八进制输出。
- **`std::hex`**：切换为十六进制输出。

_(注意：一旦设置了某个进制控制符，`cout` 会一直保持该进制状态，直到再次显式切换。)_

```cpp
#include <iostream>
#include <bitset> // 用于输出二进制格式

using namespace std;

int main() {
    int num = 42;

    // 1. 将同一个数值按不同进制输出
    cout << "Decimal: " << num << endl;
    cout << "Hexadecimal: " << hex << num << endl;
    cout << "Octal: " << oct << num << endl;

    // 注意：此时 cout 仍处于八进制模式，需显式恢复为十进制
    cout << dec;
    cout << "Back to Decimal: " << num << endl;

    // cout 没有内置二进制控制符，可借助 std::bitset<N> 输出 N 位二进制
    cout << "Binary: " << bitset<8>(num) << endl;

    // 2. 验证不同进制字面量的十进制数值（此时 cout 为十进制模式）
    int chest = 42;   // 十进制字面量
    int waist = 042;  // 八进制字面量 (4*8 + 2 = 34)
    int mouth = 0x42; // 十六进制字面量 (4*16 + 2 = 66)
    cout << "chest (42)   in dec: " << chest << endl;
    cout << "waist (042) in dec: " << waist << endl;
    cout << "mouth (0x42) in dec: " << mouth << endl;

    return 0;
}
```

输出结果：

```text
Decimal: 42
Hexadecimal: 2a
Octal: 52
Back to Decimal: 42
Binary: 00101010
chest (42)   in dec: 42
waist (042) in dec: 34
mouth (0x42) in dec: 66
```

### 字符类型与 ASCII 码

计算机底层只能存储和处理二进制数字（`0` 和 `1`）。为了让计算机能够表示文本（如字母、数字字符、标点符号），需要一套编码映射规则将每个字符对应到一个整数，**ASCII 码**便是最基础的字符编码标准。

在 C++ 中，`char`（字符型）在内存中本质上存储的就是一个 1 字节的整数（即对应的 ASCII 码值）。

除了使用 `cout << ch` 输出字符外，`std::ostream` 类还提供了一个专门的成员函数 `cout.put()`，其职责非常纯粹：**仅向输出流写入单个字符**。

- 它接收一个 `char` 类型的参数。
- 若传入整型值（如 `65` 或 `77`），它会将其隐式转换为对应的 ASCII 字符（`'A'` 或 `'M'`）并输出。
- 返回值是 `ostream&`，因此支持链式调用，例如 `cout.put('A').put('B');`。

```cpp
#include <iostream>
using namespace std;

int main() {
    char ch = 'M';
    int i = ch;
    cout << "The ASCII value of " << ch << " is " << i << endl;

    // 对字符直接做加减运算，本质上就是对其 ASCII 码值做增减
    ch = ch + 1;
    i = ch;
    cout << "The ASCII value of " << ch << " is " << i << endl;

    cout << "Display char ch using cout.put(ch): ";
    cout.put(ch).put('!').put('\n');

    cout.put(77); // 输出: M (77 是字符 'M' 的 ASCII 码)
    cout.put('\n');
    return 0;
}
```

输出结果：

```text
The ASCII value of M is 77
The ASCII value of N is 78
Display char ch using cout.put(ch): N!
M
```

### `bool` 布尔类型

C++ 中的 `bool` 类型只有两个字面值：`true`（真）和 `false`（假），在数值转换时遵循两条核心规则：

1. **数值转 `bool`（非零即真）**：数字 `0`（或空指针 `nullptr`）会被隐式转换为 `false`；任何**非零数值**（无论正负）都会被转换为 `true`。
2. **`bool` 转数值**：当把布尔值赋给 `int` 等算术类型时，C++ 标准严格规定 `true` 转换为 `1`，`false` 转换为 `0`。

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1. 非零整数（包括负数）隐式转换为 true
    bool flag = -100;
    if (flag) cout << "True" << endl;
    else cout << "False" << endl;

    // 2. 布尔值转换为整数：true -> 1, false -> 0
    int ans = true;
    int promise = false;
    cout << "ans = " << ans << ", promise = " << promise << endl;

    return 0;
}
```

### `const` 限定符详解

C++ 中的 `const`（Constant 的缩写）是一个至关重要的类型限定符，用于**向编译器声明变量、指针、引用或成员函数具有“只读（Read-only）”语义**。借助编译期不可变性检查，`const` 能有效防止意外篡改，大幅提升代码的安全性与可维护性。

以下是 `const` 在 C++ 中的 5 个核心应用场景：

#### 1. 修饰基础变量（定义常量）

最基础的用法是声明一个不可修改的常量。**注意：`const` 常量必须在声明的同时完成初始化。**

```cpp
const int MAX_USERS = 100;
// MAX_USERS = 200; // 编译错误：MAX_USERS 是只读常量
```

#### 2. 修饰指针（高频易混点）

当 `const` 与指针结合时，最稳妥的辨析口诀是**“看 `const` 位于 `*` 的左侧还是右侧”**（也可以“从右往左读”）：
_(注：国内教材对中文译名“常量指针”和“指针常量”常有混用，建议直接记忆英文原意 **Pointer to Const** 与 **Const Pointer**，彻底消除歧义。)_

- **指向常量的指针 (Pointer to Const)**
  `const` 在 `*` 的**左边**。表示**指针所指向的数据**是只读的（不能通过该指针修改值），但指针本身的指向可以改变。
  ```cpp
  int x = 10, y = 20;
  const int* p1 = &x; // 等价于 int const* p1;
  // *p1 = 30;        // 错误：不能通过 p1 修改所指对象的值
  p1 = &y;            // 正确：p1 可以改指其他地址
  ```
- **指针本身是常量 (Const Pointer)**
  `const` 在 `*` 的**右边**。表示**指针变量自身存储的地址**不可改变（从一而终），但可以通过该指针修改所指向的数据。
  ```cpp
  int* const p2 = &x;
  *p2 = 30;           // 正确：可以修改所指对象 x 的值
  // p2 = &y;         // 错误：p2 的指向一旦初始化便不可更改
  ```
- **指向常量的常指针 (Const Pointer to Const)**
  `*` 左右两侧均有 `const`，指针的指向和所指向的数据均被锁定：
  ```cpp
  const int* const p3 = &x; // 指向与目标值均不可修改
  ```

#### 3. 修饰引用（函数传参的最佳实践）

在向函数传递大型对象（如 `std::string`、`std::vector` 或自定义结构体/类）时：

- 按值传递会产生高昂的内存拷贝开销；
- 按普通引用传递又存在实参被函数内部意外修改的风险，且无法接收临时对象（右值）。

**常量引用 (`const Type&`)** 兼顾了零拷贝的高效性与只读安全性：

```cpp
void printUser(const std::string& username) {
    // username += "_admin"; // 编译错误：不可通过常引用修改数据
    std::cout << username << std::endl;
}
```

> **最佳实践**：除内置基础类型（如 `int`、`char`、`double` 直接按值传递即可）外，函数若只需读取参数而不修改它，应默认采用 `const Type&` 传参。

#### 4. 修饰类的成员函数（常成员函数）

在类中，若某个成员函数仅读取对象的状态而不修改任何普通成员变量，应在其参数列表末尾加上 `const`：

```cpp
class Account {
private:
    int balance = 1000;
public:
    // const 成员函数承诺不修改对象的逻辑状态
    int getBalance() const {
        // balance += 100; // 编译错误：const 成员函数内不能修改普通成员变量
        return balance;
    }
};
```

**核心规则**：**`const` 对象只能调用 `const` 成员函数**。如果 `getBalance()` 未标记为 `const`，那么常量对象 `const Account acc;` 将无法调用该方法。

_(补充：若确实需要在 `const` 成员函数中修改某个与外部逻辑状态无关的成员——如访问计数器、缓存标志或互斥锁 `std::mutex`，可使用 `mutable` 关键字修饰该成员变量以豁免 `const` 限制。)_

#### 5. `const` 与 `constexpr` 的区别 (C++11)

现代 C++ 引入了 `constexpr`，两者的侧重点截然不同：

- **`const`（只读语义）**：强调“在此作用域内不修改它”，其初始值可以在**运行期（Runtime）**动态计算得出。
- **`constexpr`（编译期常量）**：强调“真正的编译期常量”，其值必须在**编译阶段（Compile-time）**就能完全确定，可直接用于数组长度、模板非类型参数等严苛场景。

> **核心思想（Const Correctness 常量正确性）**：只要一个变量、指针、引用或成员函数不需要修改数据，就应当主动加上 `const`。这不仅是给编译器的优化提示，更是写给协作者最清晰的接口契约。

### C++ 浮点数详解

C++ 中的浮点数用于表示带有小数部分的实数或极大/极小的数值。由于计算机内存位数有限，C++ 采用 **IEEE 754 标准**（符号位 + 指数位 + 尾数位）存储浮点数。这意味着浮点数本质上是**对真实实数的二进制近似**，而非绝对精确值。

#### 1. 三大基础浮点类型对比

| 类型          | 典型内存占用     | 有效十进制位数 | 字面量后缀               | 典型适用场景                                                 |
| :------------ | :--------------- | :------------- | :----------------------- | :----------------------------------------------------------- |
| `float`       | 4 字节 (32 位)   | 约 6 ~ 7 位    | `f` 或 `F`（如 `3.14f`） | 图形学渲染（GPU/OpenGL）、大规模浮点矩阵或内存受限场景       |
| `double`      | 8 字节 (64 位)   | 约 15 ~ 17 位  | 无后缀（如 `3.14`）      | **默认首选**，绝大多数科学计算与日常工程业务                 |
| `long double` | 8 / 12 / 16 字节 | 约 18 ~ 21 位  | `l` 或 `L`（如 `3.14L`） | 超高精度的数值分析或天体物理计算（具体位宽依赖编译器与硬件） |

> **注意字面量陷阱**：在 C++ 中，不带后缀的小数字面量（如 `3.14`）默认是 `double` 类型。若编写 `float x = 3.14;`，编译器会先按 `double` 解析再隐式截断为 `float`；显式写成 `float x = 3.14f;` 才是直接构造 `float`。

#### 2. 核心痛点：二进制精度丢失

许多在十进制下十分简单有限的小数（例如 `0.1` 和 `0.2`），转换到二进制小数后是无限循环小数（如同十进制下的 $1/3 = 0.333\dots$）。由于尾数位长度有限，截断舍入便会产生微小的精度误差：

```cpp
double a = 0.1;
double b = 0.2;
double c = 0.3;

if (a + b == c) {
    std::cout << "相等\n";
} else {
    std::cout << "不相等\n"; // 实际输出“不相等”！因为 a + b 实际约为 0.30000000000000004
}
```

#### 3. 浮点数判等的正确姿势

由于存在舍入误差，**切忌直接使用 `==` 或 `!=` 判断两个浮点数是否相等**。正确做法是设定一个极小的容差阈值（`epsilon`），当两数之差的绝对值小于该阈值时，即视为相等：

```cpp
#include <iostream>
#include <cmath>
#include <limits>

bool isNearlyEqual(double a, double b, double eps = 1e-9) {
    // 判断两数差值的绝对值是否落在允许的误差范围内
    return std::abs(a - b) < eps;
}
```

#### 4. 浮点数开发的三大工程准则

1. **默认优先使用 `double`**：在现代 64 位 CPU 架构上，`double` 与 `float` 的硬件运算速度几乎一致，但 `double` 的有效精度高出两个数量级，能避免绝大多数累积误差。
2. **严禁用浮点数存储货币金额**：金融、支付与电商系统中，任何一分钱的精度偏差都是不可接受的。应当使用专用的十进制高精度定点数库，或统一转化为最小货币单位的**整数**存储（例如将“12.34 元”存储为整数 `1234` 分）。
3. **警惕“大数吃小数”现象**：当两个数量级相差悬殊的浮点数相加减时，较小数的有效数字会因为超出较大数的有效数位范围而在对阶时被直接舍弃。

以下代码直观演示了 `float` 仅有的 6~7 位有效数字是如何导致“大数吃小数”的：

```cpp
#include <iostream>
using namespace std;

int main() {
    float a = 2.34E+22f; // 2.34 * 10^22
    // float 仅能精确维护前 6~7 位有效数字，在末尾加 1.0f 远远超出了其精度范围
    float b = a + 1.0f;

    cout << "a = " << a << endl;
    cout << "b - a = " << b - a << endl; // 犹如往大海里滴入一滴水，1.0f 被直接舍弃
    return 0;
}
```

输出结果：

```text
a = 2.34e+22
b - a = 0
```

### C++ 的四种强制类型转换详解

为了提升类型转换的安全性与代码可读性，C++ 引入了四个命名的显式类型转换运算符，用以替代笼统的 C 风格强制转换 `(Type)value`。它们各司其职，使编译器能够实施更精准的检查。

#### 1. `static_cast`（静态转换）

`static_cast` 是日常开发中最常用的转换方式，用于**编译期**可确认关系且非多态的类型转换。

**适用场景：**

- **基本数据类型之间的转换**：如 `int` 转 `double`、`enum` 转 `int`。
- **类层次结构中的指针/引用转换**：
  - **向上转型（派生类 $\to$ 基类）**：天然安全。
  - **向下转型（基类 $\to$ 派生类）**：无运行时检查，需开发者自行保证安全（若涉及多态应改用 `dynamic_cast`）。
- **`void*` 与具体类型指针之间的互转**。

```cpp
// 1. 基本类型转换
int a = 10;
double b = static_cast<double>(a);

// 2. 类层次转换
class Base {};
class Derived : public Base {};
Base* basePtr = new Derived();
Derived* derivedPtr = static_cast<Derived*>(basePtr); // 编译期转换，需开发者确保指向关系正确
```

#### 2. `dynamic_cast`（动态转换）

`dynamic_cast` 专用于**多态类层次结构**（基类必须至少包含一个虚函数）中的安全**向下转型**。它在**运行期**借助 RTTI（运行时类型识别）检验转换是否合法。

**核心特性：**

- **转换指针时**：若转型失败（基类指针实际并未指向目标派生类对象），安全返回 `nullptr`。
- **转换引用时**：因不存在空引用，若转型失败会直接抛出 `std::bad_cast` 异常。

```cpp
class Base { public: virtual ~Base() = default; }; // 必须包含虚函数以开启 RTTI
class Derived : public Base { public: void doSomething() {} };

Base* basePtr1 = new Derived();
Base* basePtr2 = new Base();

// 成功：basePtr1 实际指向 Derived 对象
Derived* d1 = dynamic_cast<Derived*>(basePtr1);
if (d1) d1->doSomething();

// 失败：basePtr2 指向的是纯 Base 对象，d2 返回 nullptr
Derived* d2 = dynamic_cast<Derived*>(basePtr2);
```

#### 3. `const_cast`（常量性转换）

`const_cast` 专门用于添加或移除指针/引用的 `const` 或 `volatile` 限定符。它是四个转换符中**唯一**有权限移除 `const` 属性的操作符。

**适用场景与警告：**

- 仅适用于指针或引用。
- **高危警告**：如果原始变量在定义时本身就是 `const` 常量，通过 `const_cast` 强行去常并试图修改其内存值，将触发**未定义行为（Undefined Behavior）**。它合法的主要用途是兼容那些未规范添加 `const` 修饰但内部实际不修改数据的遗留第三方接口。

```cpp
const int val = 10;
const int* ptr = &val;

// 移除指针的 const 限定
int* modifiablePtr = const_cast<int*>(ptr);
// *modifiablePtr = 20; // 危险！val 本身是 const 常量，强行修改属于未定义行为

void legacyFunction(int* p); // 老旧接口：内部只读，但参数忘记写 const
legacyFunction(const_cast<int*>(ptr)); // 合法用途：适配旧 API
```

#### 4. `reinterpret_cast`（重新解释转换）

`reinterpret_cast` 是最底层、最激进的转换。它不做任何数值换算或安全检查，直接对底层的**二进制位模式（Bit Pattern）**进行重新解释。

**适用场景：**

- **指针与足够宽的整型之间的互转**（如将指针地址存入 `uintptr_t`）。
- **毫无关联的指针类型之间的强制转换**（如 `int*` 转 `char*` 以按字节观察内存布局）。
- 仅在编写硬件驱动、序列化协议、底层内存池或哈希函数时谨慎使用。

```cpp
#include <cstdint>

int a = 65;
// 将 int 变量的地址按单字节 char* 重新解释
char* charPtr = reinterpret_cast<char*>(&a);

// 将指针地址转换为无符号整数类型保存
uintptr_t ptrAddress = reinterpret_cast<uintptr_t>(&a);
```

---

> **总结：为什么要弃用 C 风格转换 `(Type)Value`？**
>
> 当使用 `(Type)Value` 时，编译器会静默地按照 `const_cast` $\to$ `static_cast` $\to$ `reinterpret_cast` 的顺序尝试组合转换。这不仅掩盖了真实的转换意图，还可能在重构时意外退化为危险的底层内存重解释，且在大型代码库中难以通过全局搜索（如 `grep`）定位排查。使用 C++ 四种命名转换符能让代码意图“自文档化”，既安全又易于审查。

### C++ 输入流：`cin`、`cin.getline()` 与 `cin.get()` 详解

在 C++ 中，`cin >>`、`cin.getline()` 和 `cin.get()` 均用于从标准输入流读取数据。它们最核心的区别在于：**如何对待空白字符（空格、Tab）**以及**如何处理输入缓冲区中残留的换行符 `\n`**。

#### 1. `cin >>`（格式化提取运算符）

最基础的输入方式，常用于读取基本数据类型（`int`、`double`）或不含空格的单个单词（`std::string` / `char[]`）。

- **读取规则**：自动跳过所有**前导空白字符**（空格、制表符 `\t`、换行符 `\n`），从第一个有效字符开始读取，直到再次遇到空白字符为止。
- **缓冲区残留**：触发停止的那个空白字符（例如回车产生的 `\n`）会**原封不动地残留在输入缓冲区中**。

```cpp
string firstName, lastName;
// 假设用户输入: "Harry Potter" 后回车
cin >> firstName; // 读入 "Harry"，遇到空格停止
cin >> lastName;  // 自动跳过中间的空格，读入 "Potter"，末尾的回车符 \n 留在缓冲区中
```

#### 2. `cin.getline()`（读取整行并丢弃换行符）

专门用于读取包含空格的**一整行文本**到 C 风格字符数组（`char[]`）中。

- **读取规则**：读取包含空格在内的所有字符，直到读满 `size - 1` 个字符或遇到换行符 `\n`。
- **缓冲区处理（关键）**：遇到换行符 `\n` 时停止读取，并**将该换行符从缓冲区中提取并丢弃**（不会存入字符数组，也不会留在缓冲区）。
- **自动结尾**：自动在字符数组末尾补上空字符 `\0`。

```cpp
char name[20];
// 输入 "Dirk Hammernose" 后按回车
cin.getline(name, 20);
// name 中存入 "Dirk Hammernose\0"，缓冲区的 \n 已被清理干净
```

_(注：若使用的是现代 C++ 的 `std::string`，则推荐使用全局函数 `std::getline(std::cin, str)`，其对换行符的处理逻辑与 `cin.getline()` 完全一致：提取并丢弃 `\n`。)_

#### 3. `cin.get()`（读取单字符或保留换行符的整行）

`cin.get()` 提供了多个重载版本：

- **读取单个字符**：`cin.get(ch)` 或 `ch = cin.get()` 会无条件读取缓冲区中的下一个字符（**包括空格和 `\n`**）。常用于手动吞掉缓冲区里残留的回车符。
- **读取整行字符串**：`cin.get(char_array, size)` 同样能读取含空格的一行文本，但它与 `cin.getline()` 有一个**致命区别**：当遇到行末的 `\n` 时，它会停止读取，并**把换行符 `\n` 留在输入缓冲区中**！

```cpp
char str1[20];
char str2[20];

cin.get(str1, 20); // 假设输入 "Hello" 后回车，\n 依然留在缓冲区首位
cin.get(str2, 20); // 一上来就撞见残留的 \n，立即结束读取！str2 变成空字符串
```

为了跨过 `cin.get(arr, size)` 留下的换行符，通常采用链式调用顺手吃掉 `\n`：

```cpp
cin.get(str1, 20).get(); // 先读入整行，紧接着调用无参 get() 将残留的 \n 读走
```

---

> **高频踩坑总结：混用 `cin >>` 与 `getline` 导致“跳过输入”**
>
> 如果代码中先执行了 `cin >> age;`（用户按下的回车符 `\n` 残留在缓冲区），紧接着调用 `cin.getline()` 或 `std::getline()`，后者会立刻读到这个残留的 `\n` 并认为输入了一个空行，从而直接跳过用户的实际输入！
>
> **解决方案**：在 `cin >>` 之后、`getline` 之前，调用 `cin.get();` 或 `cin.ignore(numeric_limits<streamsize>::max(), '\n');` 清空当前行残留的换行符。

### C++ 结构体数组

结构体（`struct`）可以将不同类型的数据组合成一个整体，而结构体数组则允许我们批量管理具有相同结构的记录：

```cpp
#include <iostream>

struct inflatable {

         << " have a combined volume of "
         << guest[0].volume + guest[1].volume << " cubic feet." << endl;
    return 0;
}
```

### C++ 共用体 (Union) 详解

共用体（`union`）是一种特殊的数据格式，它允许在**同一段内存空间**中存储不同的数据类型。尽管一个共用体可以声明多个不同类型的成员，但在任意时刻，**它只能有效持有其中一个成员的值**。

#### 1. 核心特性

- **内存共享**：共用体的所有成员共享同一个起始内存地址。
- **大小决定**：共用体占用的总字节数由其**最大的成员**决定（同时需满足平台的内存对齐要求）。
- **数据互斥覆盖**：当向共用体的某个成员赋新值时，原先存储在其他成员中的数据会被直接覆盖。

#### 2. 基本语法与示例

```cpp
#include <iostream>
using namespace std;

union ItemValue {
    int int_val;
    double double_val;
    char char_val;
};

int main() {
    ItemValue val;

    // 1. 当前存储 int
    val.int_val = 15;
    cout << "Int: " << val.int_val << endl; // 正常输出 15

    // 2. 转而存储 double，此时原先的 int_val 内存已被覆盖
    val.double_val = 1.38;
    cout << "Double: " << val.double_val << endl; // 正常输出 1.38

    // 若此时再读取 val.int_val，将读取到毫无意义的二进制解释结果（未定义行为）
    return 0;
}
```

_(注：在现代 C++17 及以后，若需要类型安全的共用体，推荐使用标准库的 `std::variant`。)_

### C++ 枚举 (Enumeration) 详解

枚举（`enum`）是一种用户自定义类型，用于为一组具名的整数常量建立语义化的集合，从而消除代码中晦涩的“魔术数字”（Magic Numbers），提升可读性与类型安全。

C++ 中的枚举分为两类：**传统枚举（Unscoped Enum）**与 C++11 引入的**强类型枚举（Scoped Enum / 枚举类）**。

#### 1. 传统枚举 (`enum`)

使用 `enum` 关键字直接定义。若未显式指定数值，首个枚举项默认为 `0`，后续枚举项依次在前一项基础上递增 `1`：

```cpp
#include <iostream>

enum Color {
    RED,      // 默认为 0
    GREEN,    // 默认为 1
    BLUE = 5, // 显式指定为 5
    YELLOW    // 在前一项基础上自动递增为 6
};

int main() {
    Color myColor = GREEN;

    // 传统枚举可隐式转换为整型
    int colorValue = myColor;
    std::cout << "Color value: " << colorValue << std::endl; // 输出 1
    return 0;
}
```

**传统枚举的两大缺陷：**

- **作用域污染**：枚举成员（如 `RED`）直接暴露在外层作用域中。若同一作用域下还有另一个枚举也包含 `RED`，就会引发重定义编译错误。
- **类型安全较弱**：支持隐式转换为 `int`，容易导致两个不同枚举类型之间发生毫无意义的比较或算术运算。

#### 2. 强类型枚举 / 枚举类 (`enum class`, C++11)

为了解决传统枚举的作用域泄漏与隐式转换问题，C++11 引入了 `enum class`（等价于 `enum struct`）：

```cpp
#include <iostream>

enum class Status {
    OK,
    ERROR,
    PENDING
};

enum class NetworkState {
    DISCONNECTED,
    CONNECTING,
    OK // 与 Status::OK 互不冲突，各自封装在独立作用域内
};

int main() {
    // 必须通过“枚举名::枚举项”访问
    Status currentStatus = Status::OK;

    // int val = currentStatus; // 编译错误！强类型枚举禁止隐式转换为整型

    // 若确需获取底层整数值，必须使用 static_cast 显式转换
    int val = static_cast<int>(currentStatus);
    std::cout << "Status value: " << val << std::endl; // 输出 0
    return 0;
}
```

**强类型枚举的核心优势：**

- **严格的作用域隔离**：必须通过 `EnumName::Member` 访问，彻底告别命名冲突。
- **强类型安全**：禁止向整型隐式转换，在编译期拦截跨类型的误用。

#### 3. 指定底层存储类型 (Underlying Type)

C++11 起，我们可以显式指定枚举在内存中的底层整型（默认通常为 `int`，占 4 字节）。这在网络协议封包、硬件寄存器映射或内存受限的嵌入式开发中非常实用：

```cpp
// 显式指定底层类型为 1 字节的 unsigned char（而非默认的 4 字节 int）
enum class Direction : unsigned char {
    UP = 1,
    DOWN = 2,
    LEFT = 3,
```

### C++ 指针核心操作总览

下面的综合示例串联了指针的六大核心用法：取址与解引用、空指针、数组指针运算、多级指针、`const` 修饰以及堆内存的动态分配与释放：

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1. 基础用法：取地址 (&) 与解引用 (*)
    int num = 10;
    int* ptr = &num;
    cout << "--- 1. 基础指针 ---\n";
    cout << "num 的初始值: " << num << "\n";
    *ptr = 20; // 通过解引用直接修改所指变量的值
    cout << "通过 *ptr 修改后 num 的值: " << num << "\n\n";

    // 2. 空指针 (nullptr) —— 现代 C++ 推荐的安全初始化方式
    int* nullPtr = nullptr;
    cout << "--- 2. 空指针 ---\n";
    cout << "nullPtr 的内存地址是: " << nullPtr << " (指向 0 地址，直接解引用会导致程序崩溃)\n\n";

    // 3. 指针与数组 (指针运算)
    int arr[3] = {100, 200, 300};
    int* arrPtr = arr; // 数组名在表达式中退化为指向首元素的指针
    cout << "--- 3. 指针运算与数组 ---\n";
    cout << "数组首元素 (*arrPtr): " << *arrPtr << "\n";
    cout << "数组第二个元素 (*(arrPtr + 1)): " << *(arrPtr + 1) << " (地址偏移了 sizeof(int) 个字节)\n";
    arrPtr++; // 指针向后步进一个元素
    cout << "执行 arrPtr++ 后，当前指向的值: " << *arrPtr << "\n\n";

    // 4. 多级指针 (指向指针的指针)
    int** ptrToPtr = &ptr; // 保存指针变量 ptr 自身的内存地址
    cout << "--- 4. 多级指针 ---\n";
    cout << "通过 **ptrToPtr 连续两次解引用访问 num: " << **ptrToPtr << "\n\n";

    // 5. const 与指针修饰
    int var1 = 50, var2 = 60;

    // 5a. 指向常量的指针 (Pointer to Const)
    const int* pToConst = &var1;
    pToConst = &var2;  // 正确：可以改变指针的指向
    // *pToConst = 70; // 错误：不能通过该指针修改所指对象的值

    // 5b. 指针本身是常量 (Const Pointer)
    int* const constP = &var1;
    *constP = 80;      // 正确：可以通过该指针修改所指对象的值
    // constP = &var2; // 错误：指针本身的指向不可更改

    cout << "--- 5. const 指针修饰 ---\n";
    cout << "var1 的值被 constP 修改为: " << var1 << "\n\n";

    // 6. 动态内存分配 (堆内存 new / delete)
    int* dynamicPtr = new int(99);
    cout << "--- 6. 动态内存分配 ---\n";
    cout << "在堆内存中动态分配的值: " << *dynamicPtr << "\n";

    delete dynamicPtr;    // 必须配对释放，否则会造成内存泄漏 (Memory Leak)
    dynamicPtr = nullptr; // 释放后立即置空，防止产生悬空指针 (Dangling Pointer)
    cout << "动态内存已释放，并将指针安全置空。\n";

    return 0;
}
```

输出结果：

```text

通过 *ptr 修改后 num 的值: 20

--- 2. 空指针 ---
nullPtr 的内存地址是: 0x0 (指向 0 地址，直接解引用会导致程序崩溃)

--- 3. 指针运算与数组 ---

数组第二个元素 (*(arrPtr + 1)): 200 (地址偏移了 sizeof(int) 个字节)
执行 arrPtr++ 后，当前指向的值: 200

--- 4. 多级指针 ---
通过 **ptrToPtr 连续两次解引用访问 num: 20

--- 5. const 指针修饰 ---
```

### C++ 指针、数组与指针算术

在 C++ 中，指针和数组有着密不可分的底层联系：

#### 1. 指针 (Pointers)

指针变量存储的不是普通数据值，而是**对象的内存地址**。

- **取地址 (`&`)**：获取变量在内存中的首地址，例如 `&stacks[0]` 获取数组首个元素的地址。
- **解引用 (`*`)**：访问指针所指向内存地址中存储的实际数值，例如 `*pw`。

#### 2. 数组名与指针的等价性

数组是一段连续分配的内存空间。在 C++ 中，数组名在绝大多数表达式中都会自动退化（Decay）为指向其首元素的指针：

- **数组名即首元素地址**：`double* pw = wages;` 完全等价于 `double* pw = &wages[0];`。
- **下标表示法与指针表示法完全等价**：C++ 编译器在底层会将下标访问 `stacks[i]` 转换为指针解引用 `*(stacks + i)`。

#### 3. 指针算术 (Pointer Arithmetic)

指针的加减运算是以**所指向数据类型的字节大小（`sizeof(Type)`）**为单位步进的：

- 当执行 `pw = pw + 1` 时，内存地址数值增加的是 `1 * sizeof(*pw)` 字节。
- 例如：`pw` 指向 8 字节的 `double`，加 1 后地址值增加 `8`；`ps` 指向 2 字节的 `short`，加 1 后地址值增加 `2`。这保证了指针加 1 后总是精准指向数组中的下一个相邻元素。

#### 4. 关键区分：`sizeof` 运算符的行为差异

虽然数组名常被当作指针使用，但 `sizeof` 对两者的求值截然不同（此时数组名不会退化）：

- **`sizeof(数组名)`**：返回**整个数组**占用的总字节数（例如 `double wages[3]` 返回 `3 * 8 = 24` 字节）。
- **`sizeof(指针变量)`**：仅返回**指针变量自身**存储地址所需的字节数（在 64 位系统中固定为 `8` 字节，32 位系统中为 `4` 字节）。

```cpp
// addpntrs.cpp -- 演示指针算术与数组的底层关系
#include <iostream>

int main() {
    using namespace std;
    double wages[3] = {10000.0, 20000.0, 30000.0};
    short stacks[3] = {3, 2, 1};

    // 获取数组首地址的两种等价写法
    double* pw = wages;     // 数组名直接代表首元素地址
    short* ps = &stacks[0]; // 显式对首元素使用取地址符 &

    cout << "pw = " << pw << ", *pw = " << *pw << endl;
    pw = pw + 1;
    cout << "add 1 to the pw pointer:\n";
    cout << "pw = " << pw << ", *pw = " << *pw << "\n\n";

    cout << "ps = " << ps << ", *ps = " << *ps << endl;
    ps = ps + 1;
    cout << "add 1 to the ps pointer:\n";
    cout << "ps = " << ps << ", *ps = " << *ps << "\n\n";

    cout << "access two elements with array notation\n";
    cout << "stacks[0] = " << stacks[0]
         << ", stacks[1] = " << stacks[1] << endl;
    cout << "access two elements with pointer notation\n";
    cout << "*stacks = " << *stacks
         << ", *(stacks + 1) = " << *(stacks + 1) << endl;

    cout << sizeof(wages) << " = size of wages array\n";
    cout << sizeof(pw) << " = size of pw pointer\n";
    return 0;
}
```

输出结果：

```text
pw = 0x7ff7b55dc1d0, *pw = 10000
add 1 to the pw pointer:
pw = 0x7ff7b55dc1d8, *pw = 20000

ps = 0x7ff7b55dc1c6, *ps = 3
add 1 to the ps pointer:
ps = 0x7ff7b55dc1c8, *ps = 2

access two elements with array notation
stacks[0] = 3, stacks[1] = 2
access two elements with pointer notation
*stacks = 3, *(stacks + 1) = 2
24 = size of wages array
8 = size of pw pointer
```

### 动态创建结构体与成员访问（`.` 与 `->`）

访问结构体成员有两种运算符，取决于手头的标识符是**结构体实例**还是**结构体指针**：

- **点运算符 (`.`)**：当标识符是**结构体变量名**（或解引用后的结构体 `(*ps)`）时使用，如 `(*ps).volume`。
- **箭头运算符 (`->`)**：当标识符是**指向结构体的指针**时使用，如 `ps->volume`（本质上是 `(*ps).volume` 的语法糖）。

```cpp
// newstrct.cpp -- 使用 new 动态分配结构体并访问其成员
#include <iostream>

struct inflatable {
    char name[20];
    float volume;
    double price;
};

int main() {
    using namespace std;
    inflatable* ps = new inflatable; // 在堆上动态分配结构体内存

    cout << "Enter name of inflatable item: ";
    cin.get(ps->name, 20);           // 方式 1：使用箭头运算符 ->
    cout << "Enter volume in cubic feet: ";
    cin >> (*ps).volume;             // 方式 2：先解引用 *ps，再使用点运算符 .
    cout << "Enter price: $";
    cin >> ps->price;

    cout << "Name: " << (*ps).name << endl;              // 方式 2
    cout << "Volume: " << ps->volume << " cubic feet\n"; // 方式 1
    cout << "Price: $" << ps->price << endl;             // 方式 1

    delete ps; // 释放堆内存
    return 0;
}
```

交互输出示例：

```text
Enter name of inflatable item: mollae
Enter volume in cubic feet: 36.789
Enter price: $329.32
Name: mollae
Volume: 36.789 cubic feet
Price: $329.32
```

### 用指针向函数传递与处理数组

在 C/C++ 中，函数参数中的 `int arr[]` 在编译器看来完全等价于指针 `int* arr`。通过指针来传递和处理数组具有极高的运行效率与操作灵活性：

- **极高的内存与时间效率**：若将包含数万个元素的数组按值拷贝给函数，会产生巨大的内存开销与复制延迟。通过指针传参，仅需复制一个首地址（64 位系统下仅 8 字节），彻底避免了深拷贝。
- **灵活切片与操作子区间**：借助指针算术（如 `cookies + 4`），只需传入偏移后的起始地址并指定元素个数，同一个函数就能直接处理数组的任意连续子区间，无需额外拷贝构造新数组。
- **支持原地修改（In-place Modification）**：指针将原数组的真实内存地址暴露给函数（若不希望函数修改原数组，应声明为 `const int arr[]`）。函数内的排序、清洗等操作会直接作用于原数组。
- **突破编译期大小限制**：普通静态数组的长度必须在编译期确定；而结合指针与动态内存分配（如 `new int[n]`），可以在运行期按需创建可变长度的数组。
- **泛型遍历与 STL 迭代器的基石**：通过指针递增（`ptr++`）与解引用（`*ptr`）遍历连续内存的模式，正是 C++ 标准模板库（STL）中**迭代器（Iterator）**设计的核心原型。

```cpp
// arrfun2.cpp -- 数组作为函数参数时的指针退化与子区间操作
#include <iostream>

const int ArSize = 8;
int sum_arr(int arr[], int n); // 这里的 int arr[] 等价于 int* arr

int main() {
    int cookies[ArSize] = {1, 2, 4, 8, 16, 32, 64, 128};

    std::cout << cookies << " = array address, ";
    std::cout << sizeof(cookies) << " = sizeof cookies\n";

    int sum = sum_arr(cookies, ArSize);
    std::cout << "Total cookies eaten: " << sum << std::endl;

    // 仅计算前 3 个元素的和
    sum = sum_arr(cookies, 3);
    std::cout << "First three eaters ate " << sum << " cookies.\n";

    // 利用指针偏移 cookies + 4，从第 5 个元素开始计算后 4 个元素的和
    sum = sum_arr(cookies + 4, 4);
    std::cout << "Last four eaters ate " << sum << " cookies.\n";
    return 0;
}

int sum_arr(int arr[], int n) {
    int total = 0;
    std::cout << arr << " = arr, ";
    // 注意：此处 arr 已退化为指针变量，sizeof(arr) 返回的是指针本身的大小（8 字节）
    std::cout << sizeof(arr) << " = sizeof arr\n";
    for (int i = 0; i < n; i++) {
        total = total + arr[i];
    }
    return total;
}
```

输出结果：

```text

0x7ff7b42801c0 = arr, 8 = sizeof arr
Total cookies eaten: 255
0x7ff7b42801c0 = arr, 8 = sizeof arr
First three eaters ate 7 cookies.
0x7ff7b42801d0 = arr, 8 = sizeof arr
Last four eaters ate 240 cookies.
```

### C++ 函数指针

与数据变量一样，编译后的函数机器码同样存储在内存中，因此函数也有自己的入口地址。**函数指针**就是专门用来保存函数入口地址的指针变量，常用于实现**回调函数（Callback）**与策略模式：

```cpp
#include <iostream>

// 定义两个函数签名（返回类型与参数列表）完全相同的普通函数
int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}

// 将函数指针作为参数传递（实现回调机制）
// func_ptr 是一个指向“接受两个 int 参数并返回 int 的函数”的指针
void process_numbers(int x, int y, int (*func_ptr)(int, int)) {
    int result = func_ptr(x, y); // 通过函数指针调用外部传入的策略函数
    std::cout << "Processing result: " << result << std::endl;
}

int main() {
    // 1. 声明函数指针
    // 语法：返回值类型 (*指针变量名)(参数类型列表);
    // 注意：(*operation) 外侧的括号绝不能省略，否则会变成声明一个返回 int* 的普通函数
    int (*operation)(int, int);

    // 2. 将函数地址赋给指针（函数名即代表函数的入口地址）
    operation = add;

    // 3. 通过函数指针调用函数
    std::cout << "10 + 5 = " << operation(10, 5) << std::endl;

    // 4. 动态切换指向另一个同签名的函数
    operation = subtract;
    std::cout << "10 - 5 = " << operation(10, 5) << std::endl;

    // 5. 实际应用：将不同的函数作为参数传入通用处理流程
    std::cout << "\n--- Passing functions as arguments ---" << std::endl;
    process_numbers(20, 8, add);      // 注入加法逻辑
    process_numbers(20, 8, subtract); // 注入减法逻辑

    return 0;
}
```

### C++ 引用 (Reference) 详解

引用是 C++ 中非常优雅且高频使用的特性。简单来说，**引用就是为一个已存在的变量起了一个“别名（Alias）”**。对引用的任何读写操作，都直接作用于它所绑定的原变量。

```cpp
int a = 10;
int& ref = a; // ref 是 a 的引用（别名）

ref = 20;     // 修改 ref 的值，a 的值也随之变为 20（两者代表同一块内存实体）
```

#### 1. 引用的四大核心规则

- **声明时必须初始化**：引用在定义的同时必须立即绑定到一个有效的实体变量上，不能像指针那样先声明后赋值（`int& ref;` 会直接编译报错）。
- **从一而终（不可重新绑定）**：引用一旦与某个变量绑定，终生都只代表该变量，无法改绑到其他变量。后续若执行 `ref = b;`，其含义是**把 `b` 的值赋给 `ref` 所代表的原变量 `a`**，而非让 `ref` 改作 `b` 的别名。
- **不存在空引用**：不同于指针可以指向 `nullptr`，引用必须绑定到一块合法存在的对象内存。
- **语法零负担**：在语义层面上，引用与原变量共享同一个内存地址（`&ref == &a`）；在底层汇编实现上，编译器通常将其作为自动解引用的常指针（`Type* const`）处理。

#### 2. 引用的三大应用场景

##### (1) 作为函数输出/修改参数（替代指针传参）

在 C 语言中，若要在函数内修改外部实参，必须传入指针并频繁解引用；而 C++ 的引用既避免了拷贝开销，又省去了繁琐的 `&` 和 `*` 符号，让代码直观自然：

```cpp
// 使用引用实现交换函数
void swap(int& x, int& y) {
    int temp = x;
    x = y;
    y = temp;
}

int num1 = 5, num2 = 10;
swap(num1, num2); // 直接传入变量即可原地交换
```

##### (2) 常量引用（`const Type&`）—— 大对象只读传参首选

当向函数传递大型对象（如 `std::string`、`std::vector`）且不希望函数内部修改它时，使用 `const Type&` 既能实现零拷贝的高效传递，又能提供编译期只读保护：

```cpp
void printMessage(const std::string& msg) {
    // msg = "new text"; // 编译错误：常量引用不可修改
    std::cout << msg << std::endl;
}
```

##### (3) 作为函数的返回值

函数返回引用时，函数调用表达式可以作为**左值（Lvalue）**直接出现在赋值号左侧，或支持链式调用（如 `cout << a << b`）。最典型的例子是重载下标运算符 `operator[]`，返回元素引用使得我们可以直接写出 `arr[0] = 5;`。
_(注意：切勿返回局部变量的引用，因为局部变量在函数返回时即被销毁，会导致悬空引用！)_

#### 3. 引用与指针的核心对比

| 维度           | 引用 (Reference)             | 指针 (Pointer)                            |
| :------------- | :--------------------------- | :---------------------------------------- |
| **初始化要求** | 声明时必须立即绑定初始化     | 可以先声明，稍后再赋值                    |
| **重新绑定**   | 终生不可更改绑定对象         | 可随时改指其他内存地址（非 `const` 指针） |
| **空值语义**   | 不存在合法的空引用，无需判空 | 可以为 `nullptr`，解引用前需判空          |
| **语法形态**   | 与普通变量用法完全一致       | 需显式使用 `&` 取址、`*` 或 `->` 解引用   |
| **多级嵌套**   | 不存在“引用的引用”           | 支持多级指针（如 `int**`）                |

> **现代 C++ 编程准则**：**优先使用引用，按需使用指针**。只有当业务场景明确需要“可重新指向不同对象”或“允许为空（`nullptr`）”的语义时，才使用指针。

### C++ 中的函数模板 (Function Template) 详解

在强类型的 C++ 中，若想编写一个通用的“求两数最大值”或“交换两个变量”的函数，按传统方式需要为 `int`、`double`、`std::string` 等每种类型编写逻辑完全重复的重载函数。

**函数模板（Function Template）**正是为了解决这一痛点而生。它就像一套**“通用模具（Blueprint）”**，允许我们编写与具体数据类型解耦的**泛型代码（Generic Programming）**。在编译阶段，编译器会根据调用时传入的实参类型，自动实例化（Instantiation）出对应类型的具体函数。

```cpp
#include <iostream>
#include <string>

// 1. 声明函数模板
// template 关键字声明模板开始；typename T 定义类型参数占位符 T（typename 也可写为 class，二者在此处完全等价）
template <typename T>
T GetMax(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    // 情况 A：隐式类型推导 (Implicit Type Deduction)
    int i1 = 10, i2 = 20;
    // 编译器根据实参类型自动推导出 T 为 int，并生成 GetMax<int>(int, int)
    std::cout << "Max int: " << GetMax(i1, i2) << std::endl;

    double d1 = 3.14, d2 = 2.71;
    // 编译器自动推导出 T 为 double，生成 GetMax<double>(double, double)
    std::cout << "Max double: " << GetMax(d1, d2) << std::endl;

    // 情况 B：显式指定模板实参 (Explicit Template Arguments)
    int num = 5;
    double pi = 3.14;
    // std::cout << GetMax(num, pi);
    // 上行会编译报错：实参一个为 int，一个为 double，编译器无法唯一确定 T 的类型

    // 解决方案：在尖括号 <> 中显式指定 T 为 double，此时 int 型的 num 会隐式转换为 double
    std::cout << "Max mixed: " << GetMax<double>(num, pi) << std::endl;

    // 情况 C：应用于标准库或自定义类型
    std::string s1 = "Apple", s2 = "Banana";
    // 只要目标类型支持模板内部使用的操作（如 std::string 重载了 '>' 运算符），模板即可正常工作
    std::cout << "Max string: " << GetMax(s1, s2) << std::endl;
```
